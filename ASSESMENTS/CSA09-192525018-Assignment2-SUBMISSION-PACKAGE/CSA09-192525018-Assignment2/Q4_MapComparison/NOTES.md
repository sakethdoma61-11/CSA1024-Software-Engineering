This starter benchmarks one inventory size (10,000 medicines) and 100,000 lookups. Extend it to at least three sizes as required by the assignment. HashMap has average O(1) put/get and no ordering guarantee; TreeMap provides key order with O(log n) basic operations; LinkedHashMap preserves insertion order with average O(1) basic operations. A HashMap code-order report needs sorting the keys; a LinkedHashMap insertion-order report is naturally available.
